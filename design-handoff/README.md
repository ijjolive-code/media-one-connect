# Media One Connect design handoff
Prepared 27 October 2026. Asset curation and proposed UI direction, not an implemented app redesign.

## Start
1. Extract this ZIP.
2. Open ASSET_REVIEW.html in your browser to review every photograph, selected roles and the actual fonts. It works locally without an account or network connection.
3. Copy this complete folder into your existing repository as design-handoff/. Keep its assets subfolders intact.
4. Ask Codex to read CODEX_START_HERE.md and execute that task.
5. Review the three Home concepts in your private Codespace before selecting a direction.

If using Codespaces: drag the extracted folder into the project Explorer and name it design-handoff. Ask Codex to check the resulting file paths and repository status. Merely uploading this ZIP to ChatGPT does not put it in your GitHub repository. Do not commit only the ZIP and expect assets to be available as normal files.

## Contents
27 original hotel/venue images with clean filenames; 2 original webfont binaries with readable filenames; 5 previously supplied visual references; an asset inventory with original names, dimensions, hashes, intended roles and crop notes; design brief; font notes; quality checklist; Codex task.

All images were visually reviewed as contact sheets. Font metadata and raster specimens were inspected. Crop suggestions are composition guidance, not tested final responsive crops. The app has not been changed, fonts have not been installed into it, and no paid AI calls were made.

## Selection
Recommended starting assets: rooms-lifestyle-teal for personality; coco-pool-night for evening hospitality; garden-lifestyle for social energy. Primary venue cards: ciao-bella-interior, qwerty-day, coco-terrace-day, garden-lifestyle. Keep the exterior for arrival/hotel information rather than making every Home concept a building photograph.

## Remaining gaps
No new logo or brand manual was included in these uploads; use the existing repo sources. Only regular font weights supplied. No M12go-specific image, dedicated food/drink imagery or reception image in this batch. These are future improvements, not blockers for the first concepts. Existing account functionality, booking integrations and concierge quality are not solved by this pack.
