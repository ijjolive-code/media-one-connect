## Manual references

Page 23 specifies web values:
- Primary charcoal: #3C474F
- Primary deep pink: #D92745
- Accent deep teal: #31657E
- Accent light blue: #74CCD5

Use the explicit Web hex entries. The manual's separately printed RGB entries differ from them. Primary colours dominate; accents are used sparingly.

Pages 26-28 name:
- English headings/subheadings: Chartwell Bars.
- English body: Geomanist.
- Arabic headings: GE Modern.
- Arabic body: Shilia.

Verify font files' internal names and rendered appearance against the manual before implementing. The typography pages are print-oriented: adapt sizing, spacing, line height and alignment for readable mobile interfaces. Do not apply print settings mechanically to app controls or chat. The system fallbacks on page 29 apply to office/email contexts; they do not prove approval of a particular app font.

The voice is short, conversational and confident, with simple language and restrained humour. Avoid forced "cool" wording or overhyped promises.
